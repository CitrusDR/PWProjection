## 1.0.5 —— 稳定性修复与已知问题说明（内部构建 `2026-10-09.119`）

> 1.0.1 → 1.0.5 是一连串**玩家实测报出来的修复**，功能没有变化，但手感和稳定性好了很多。

**修复（均有日志实证）**

* **高度自适应后的微调 / 朝向现在会被记住**：以前"已有进度的那一处"不会更新偏移 ⇒ 关掉再打开投影会**跳回旧高度**、重放时两次吸附高度不一致、**地板对不齐** ✗
* **不再"被拒一次就永久只吸 x/y"**：原来高度差只有几厘米时会被误判成"挪不动" ⇒ 那一处之后**所有建筑都不吸高度** ✗ ⇒ 现在被拒之后**继续吸高度**，日志写清原因（多半是素材不足 / 位置不合法）
* **高度学习可重试**：以前"学过一次就封口"，而那次可能压根**没挪成** ⇒ 投影一直比实物低、地基越放越对不上 ✗ ⇒ 现在只有**真挪成功**才封口，没挪成最多重试 3 次
* **首次上手不再卡住**：「渲染能力探测」默认绑 **`N`**（原来默认 F24 = 按不到，新玩家会以为模组坏了）
* **设置页の「正在捕获按键」标志卡住时不再让整个模组变哑巴**：现在会留痕（日志写 `跳过 … CaptureActive=true`），并且**超过 60 秒自动忽略它**恢复按键
* **重载预算安全阀**（`.118` 起）：同一进程重载超过 6 次时，这一次**不再注册放置钩子 / 不做启动清扫**（其它功能全在），并在屏幕与日志里提示"请重启游戏" ✓
* **工坊更新不会丢数据**（实测验证）：`pwpr_config.json` / `pwpr_keys.json` / `pwpr_placements.json` / `pwpr_meshmap.json` 在 1.0.0 → 1.0.1 更新后 **逐字节一致** ✓
* 修复工坊页面**缩略图没传上去**的问题（打包脚本只认 `.png`，而玩家换成了 `.jpg`）

**新增配置**

* `options_apply_mode`（默认 `"restart_mod"` = 保存即刻生效）—— 可改 `"game_restart"`：保存后**不重载模组**、只提示重启游戏。

**已知问题（已写进安装说明）**

* **改键之后不要快速连点保存**：每次保存都会重载本模组，而改键这条路会让设置框架反复重载（实测约 **0.44 秒一轮**），几十轮后游戏可能卡死 ✗；不改内容时随便点（不会重载）✓
* 偶发崩溃（已收集到两份转储，栈在 `UE4SS.dll`）—— 仍在排查，欢迎带 `crash_*.dmp` + `pwpr.log` 反馈

## 1.0.0 —— 首个公开发布版（内部构建 `2026-10-09.112`）

**首发功能**

* **采集 → 蓝图**: 站进基地按 `Y` 把建筑采集成蓝图（纯 JSON，可备份/分享；采集半径可调，`0` = 全部）
* **投影**: 按 `J` 加载蓝图、`K` 放下/收起 —— 半透明蓝色轮廓，材质可换
* **★ 建造吸附**: 放下建筑的**那一刻**自动吸附到投影对应的位置（不用按任何键）；放好的那件
  立刻从投影里消失，不再和实物重合闪烁
* **高度自适应 / 高度学习**: 水面或特殊地形上"游戏允许的高度"和投影记录的高度不一致时，
  自动把**整份投影的高度**挪到游戏允许的位置（并在真正建出来后按实际高度校准）；超出上限时
  明确提示"请手动微调"，不再静默放弃
* **位置 + 进度记忆**: 按蓝图记住上次投影放在哪、以及已经建到哪（可存**多处**放置记录，`U` 切换）；
  重进游戏/换蓝图回来时按 `K` 沿用位置，已建好的部分直接不画
* **分层显示**: `L` 按高度分层显示，间距可调
* **投影微调**: 方向键平移/旋转/换材质（`F9` 切模式），步长可调；`H` 一键重新定位到脚下
* **游戏内设置面板**（需 Mod Options Framework）: 总开关 + 核心按键 + 可选按键 + 数值项，
  可以**在游戏里改键**、不用改文件
* **中文日志与诊断**: `pwpr.log` 里每一步都有中文说明（含 `[bsnap]` 吸附判读行、黑匣子标记）

**发布前修掉的两个上手/稳定问题**

* **首次上手**: 「渲染能力探测」默认绑 **`N`** —— 它决定投影能不能解锁，不能默认解绑
  （此前装了设置框架的用户默认按不到 `N`，会以为模组坏了）
* **高度修正的作用域**: 高度自适应/降级的记忆改成按"**这一处投影**"（蓝图 + 锚点）分组 ——
  换一处或换一张蓝图后会重新把投影高度对齐到游戏允许的位置（此前换地方之后投影不再移动，
  导致地基上的建筑放不下去）

**已知限制**：见 `安装与使用.md` 第五节（预览不跟吸 / 拆掉不自动恢复 / 拼装建筑只画主件 /
`blueprint` 模式未完成 / 联机未验证）。
