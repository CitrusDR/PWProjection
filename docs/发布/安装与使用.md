# PWProjection —— 安装与使用

> Palworld（幻兽帕鲁）建筑**投影 / 蓝图**模组：把盖好的基地**采集**成蓝图，在别的存档里把蓝图
> **投影**成半透明蓝色轮廓，照着它一块块盖回去；**放下建筑的那一刻自动吸附到对应位置**，
> 放好的那件立刻从投影里消失。风格对标 Minecraft 的 **Litematica**。
>
> 作者 **CitrusDR**（B 站: **柑橘味快乐水**） · 源码/反馈: <https://github.com/CitrusDR/PWProjection>
> 演示视频: <https://www.bilibili.com/video/BV1PHHy6pEnz/>

---

## 一、需要什么

| 项 | 要求 |
|---|---|
| 游戏 | **Palworld 1.0.x**（Steam 版） |
| 前置 | **UE4SS**（本模组跑在 UE4SS 的 Lua 环境里，**必须装**） |
| 推荐 | **Mod Options Framework**（可选）—— 装了就能在游戏 **Esc → 模组选项** 里改键 / 调数值 |

> ⚠️ 本模组**不打包** UE4SS，也**不打包**任何第三方模组，请自行安装。

## 二、安装

### 方式 A（创意工坊，省事）

1. 订 **UE4SS Experimental (Palworld)**（工坊前置，本模组设为依赖，一般会一起装）；
2. 订 **PWProjection**；
3. 进游戏 → **Options → Mod Management → Enable Mod 打开** → 勾上这两个 → **Save**（游戏会重启）；
4. 进世界后按 **`N`** 跑一次能力探测（**第一次必须**，通过后自动解锁投影）。

### 方式 B（手动装 / 从 N 网、GitHub 下载的压缩包）

1. 先装 UE4SS（把它的 `ue4ss` 与 `UE4SS.dll` 等按它的说明放进游戏；工坊版会自己到位）；
2. 把压缩包里的 **`PWProjection`** 整个文件夹放到：

   ```
   <Palworld>\Mods\NativeMods\UE4SS\Mods\PWProjection\
   ```

   （`Scripts\main.lua` 必须在这个位置：`...\Mods\PWProjection\Scripts\main.lua`）
3. 在 **`<Palworld>\Mods\NativeMods\UE4SS\Mods\mods.txt`** 里加一行（名字要和文件夹名一致）：

   ```
   PWProjection : 1
   ```
4. 重启游戏 → 进世界 → 按 **`N`** 跑一次能力探测。

> 🧹 **卸载**: 把 mods.txt 里那行删掉（或改成 `PWProjection : 0`），然后删掉 `Mods\PWProjection` 文件夹。
> 想保留设置与建造进度就留着 `Scripts\pwpr_config.json` / `pwpr_keys.json` / `pwpr_placements.json`。

## 三、第一次使用（顺序）

```
① 进世界、能自由走动（别在载入画面按任何键）
② 按 N    → 渲染能力探测：通过后自动解锁投影（写进 pwpr_config.json 的 ghost_enabled = true）
③ 站到基地里 按 Y  → 采集建筑、生成蓝图
④ 按 J    → 加载蓝图（多张时循环切下一张）
⑤ 按 K    → 放下投影（蓝色半透明）；再按一次收起
⑥ 进建造模式正常摆件 → 放下时自动吸附到投影对应的位置
```

**核心键（开箱可用）**：`N` 探测 · `Y` 采集 · `J` 加载蓝图 · `K` 投影放/收 · `L` 分层

**其余键默认不绑**（`H` 重新定位到脚下、`U` 换一处记录、`F9` 方向键模式、`F7` 帮助/状态…）：
去 **Esc → 模组选项 → PWProjection** 里给想要的那几项设一个键，**点保存**即可。

* 装了 **Mod Options Framework** 才有上面那个设置页；没装的话这些键按 `pwpr_config.json` 的默认值走
  （`H` / `U` / `F9` / `F7` / `F8` 直接可用）。
* 改配置/改键后**要重启游戏**才生效（只有 `F8` 重载 `pwpr_config.json` 不用重启）。

**投影微调**：方向键平移；`F9` 切模式后方向键变成旋转/材质；小键盘（如果有）也能用。
投影摆错位置就站在正确的地方按 **`H`**（重新定位到脚下；同一张蓝图可以存**多处**放置记录，`U` 切换）。

## 四、常见问题

| 现象 | 怎么办 |
|---|---|
| 按 `K` 提示"投影没解锁" | 先按 **`N`** 跑能力探测（通过后会自动解锁）；确认没把 `ghost_enabled` 手动设成 false |
| 按 `N`/`H`/`U` 没反应 | 这些键在设置页里可能**没绑**：**Esc → 模组选项 → PWProjection** 给它们设键（`N` 默认绑，`H`/`U` 默认不绑） |
| 改了键/配置没生效 | 改键/保存设置后**建议重启一次游戏**（在「模组选项」里点保存只会**重载本模组**；重载后按键注册可能被设置框架自己的按键绑定占着 ⇒ 有时会"按了没反应"）。`pwpr_config.json` 按 `F8` 即可。设置页点保存会**清掉已加载的蓝图与已放下的投影** ⇒ 重新按 J + K 即可，同一处的建造进度会自动续上 |
| 玩着玩着**所有快捷键都没反应**了（移动正常）| 这是设置框架的「正在捕获按键」标志卡住了（`.114` 起连续卡 60 秒会自动忽略它并恢复；日志里能看到 `跳过 … CaptureActive=true` 那些行）。**重启游戏**一定能恢复 |
| ⚠️ **已知问题：改键之后连点保存，可能把游戏卡死** | **在设置页「改一个键」之后不要快速连点保存**。原因：保存一次就会**重载本模组**一次，而改键这条路会让框架反复认为"值又变了"⇒ 连着重载（实测约 **0.44 秒一轮**，几十轮后游戏卡死）。<br>**怎么用才安全**：① 改完**点一次**保存；② 需要连着改多项时，改完一项就**等它生效**再改下一项；③ **不改内容**时随便点保存（框架认为没变化、不会重载 => 实测连点二三十次都没事）。<br>**万一卡住了**：直接结束进程重开游戏即可 —— `pwpr_config.json` / `pwpr_keys.json` / `pwpr_placements.json` / `pwpr_meshmap.json` **都不会丢**（已实测验证）✓<br>**想彻底避开**：在 `Scripts\pwpr_config.json` 里加一行 `"options_apply_mode": "game_restart"` ⇒ 保存后**不再重载**，改为提示"请重启游戏"（功能全在，只是改完要重启游戏才生效）|
| 放下时没吸附上 | 看日志 `Scripts\pwpr.log` 里的 `[bsnap]` 行：会写清"太远 / 类型没对上 / 被门槛放过 / 游戏拒绝了"。常见的是**投影本身没摆对**（按 `H` 重放） |
| 投影和实物交替闪 | 放下那一件本应立刻消失；若还在闪，按 `F7` 看状态，或调 `ghost_hide_placed_cm` |
| 想确认跑的是哪一版 | 看 `pwpr.log` 第一行的 `构建标记:` |
| 日志在哪 | `<Palworld>\Mods\NativeMods\UE4SS\Mods\PWProjection\Scripts\pwpr.log`（**报问题时把这个文件发出来**） |
| 想删掉"记住的位置/进度" | 先关游戏：全删 = 删 `Scripts\pwpr_placements.json`；细粒度用仓库里的 `tools\resume_tool.py` |

## 五、已知限制（不是 bug）

* **游戏里的半透明预览不会跟着吸** —— 只有**真正放下去的那一件**会精确落位（引擎的预览 Lua 改不了）；
* **拆掉的建筑不会自动恢复投影**（那条自动扫描实测会崩游戏，默认关闭）⇒ 拆完按 `K` 收起再放一次；
* **多件拼装建筑只画主件近似**（伐木场、采石场等）；
* **`blueprint` 模式未完成**（配置里设了会告警）⇒ 请用默认的 `align`；
* **联机（多人）未验证**。
