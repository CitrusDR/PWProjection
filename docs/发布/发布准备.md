## ① 结论：两平台都能发，而且工坊是**官方支持**的类型

| | Steam 创意工坊 | Nexus Mods |
|---|---|---|
| 能不能发**纯 UE4SS Lua** 模组 | **能** —— 官方把 `Lua (UE4SS)` 列为 5 种受支持类型之一，工坊**不是**只收 `.pak` | **能** —— N 网 Palworld 分区本来就有大量 UE4SS 模组，且有**官方 Vortex 扩展**支持 Lua 类型 |
| 装到哪 | `Mods\NativeMods\UE4SS\Mods\PWProjection\`（**和我们现在的路径完全一致** ✓） | 同一个位置（手动/Vortex） |
| 用户怎么装 | 订阅 + 游戏内 `Options → Mod Management` 勾选 → Save | Vortex 一键，或解压到 `Mods\` + `mods.txt` 加一行 |
| 前置依赖 | 工坊有 **`UE4SSExperimentalPW`**（你本机就是这个，`publishedfileid 3625223587`）⇒ 依赖它，订阅时一起装 | 描述里写明"需要 UE4SS"，并用 **Requirements** 字段挂前置 mod |
| 谁处理**启用** | 游戏自己的 Mod Manager（**不要**打包 `enabled.txt` / `mods.txt`） | 手动改 `mods.txt`（Vortex 会自动写） |
| 更新 | 改 `Version` → 上传，用户自动更新 | 给同一个文件追加新版本 + changelog（**追加**语义） |

**关键情报（你本机实测验证过的）**：你机器上的 UE4SS 本身就是**工坊物品**
（`Mods\NativeMods\UE4SS\Info.json`: `PackageName=UE4SSExperimentalPW`, `Author=Oak`,
`InstallRule=[{Type:"UE4SS",Targets:["."]}]`）⇒ 我们的模组以 `Type: "Lua"` 发布到工坊后，
会被官方 loader 装到 `Mods\NativeMods\UE4SS\Mods\PWProjection\Scripts\`，并自动写进
`Mods\NativeMods\UE4SS\Mods\mods.txt` 与 `Mods\PalModSettings.ini` 的 `ActiveModList`
—— **用户完全不需要跑 deploy.ps1**（PowerShell 脚本也就不进包，顺带避开杀软误报）。

## ③ 只有你能做的（照做清单）

### A. 通用（两个平台都要）

- [ ] **A1. 换掉缩略图/主图**：`mod\PWProjection\workshop\thumbnail.png` 现在是**占位图**（脚本生成的）。
      换一张真实的游戏截图（工坊方形/接近方形更好看；**文件必须 < 1MB**，PNG/JPG 都行）。
      N 网主图建议 **1920×1080 PNG/JPG**，另准备 **2–4 张**画廊图（游戏内投影 + 建造吸附各一张最有说服力）。
- [ ] **A2. 决定「`H` 重新定位」要不要也默认绑定**（见 ④-2）。
- [ ] **A3. 跑一次打包**（改 `Version` 就出新版本）。★ **一行写完、别粘成两行**
      （实测踩过: `cd <目录> powershell ...` 会被 PowerShell 当成 `cd` 的参数而报
      `Set-Location : 找不到接受实际参数"powershell"的位置形式参数`）：
      ```powershell
      powershell -NoProfile -ExecutionPolicy Bypass -File D:\dsh-workspace\palworld-litematica\tools\make_release.ps1
      ```
      已经打过同一个版本号、想重打就加 `-Force`（默认会拒绝覆盖，防手滑）：
      ```powershell
      powershell -NoProfile -ExecutionPolicy Bypass -File D:\dsh-workspace\palworld-litematica\tools\make_release.ps1 -Force
      ```
- [ ] **A4. 发布前先自己测一次"工坊订阅"路径**（见 ④-3 的必测项）——**这是唯一能证明
      "订阅用户开箱可用"的方法**，也顺便验证"更新后用户设置/进度还在不在"。

### B. Steam 创意工坊

- [ ] **B1. 工具**：Steam 库里应该有 **Palworld Mod Uploader**（拥有 Palworld 才有；
      没有就从 <https://github.com/pocketpairjp/PalworldModUploader/releases> 下载）。**先启动 Steam 并登录**。
- [ ] **B2. 首次会要求接受 Steam 创意工坊法律协议**（工具会弹提示）。
- [ ] **B3. 设置 Workshop Content Directory** = `<Steam>\steamapps\workshop\content\1623730`
      （没有这个文件夹就自己建一个）。
- [ ] **B4. `Create New Mod`** → 选类型 **Lua** → 把 `backups\PWProjection\发布\1.0.0\workshop_package\`
      里的东西放进去（`Info.json` + `thumbnail.png` + `Scripts\`）→ 点 **`Save Info.json`**。
      （★ 别在工坊目录里改代码——游戏不读那里的改动；要改就改 `Mods\NativeMods\UE4SS\Mods\PWProjection\` 再拷回去。）
- [ ] **B5. 点 `Upload To Steam`** → 填 Change Notes → 上传完会自动打开工坊页。
      **新物品默认是 Hidden（只有你能看到）** —— 正好用来先测。
- [ ] **B6. 在工坊页面上补齐**：描述（`页面文案.md` 第 4 节整段粘贴）、**Required Items → 加 UE4SS Experimental (Palworld)**、
      额外预览图、可见性（测好了再改 **Public**）。
- [ ] **B7. 以后更新**：改 `Info.json` 的 `Version` → 重新打包 → 同一个条目再点 `Upload To Steam`。
      **只改图/描述不用动 `Version`。**

### C. Nexus Mods

- [ ] **C1. 注册 + 邮箱验证**（免费账号即可，**不需要 Premium**）。建议顺手开 2FA。
- [ ] **C2. 建页**：站点右上角 **Upload a mod** → 填 Name / Summary(≤350) / Category / Version=1.0.0
      → 描述编辑器右上角点 `[ ]` 切到 **BBCode** 再粘贴（`页面文案.md` 第 5 节）。
      ★ **API 不能建页**（官方 v3 API 没有"创建模组页"的端点）⇒ 这一步只能手工。
- [ ] **C3. 设 Tags**（含 `English`）、**Permissions**（照 `页面文案.md` 第 6 节的推荐表点）、
      不要勾成人内容、**不要**留空占位页。
- [ ] **C4. Files 页上传** `PWProjection-1.0.0.zip`：File name `PWProjection-1.0.0`、File version `1.0.0`、
      Category **Main Files**、File description 写"解压到 `Mods\NativeMods\UE4SS\Mods\`"。
      保持 `allow_mod_manager_download` 打开（让 Vortex 能一键装）。
- [ ] **C5. 等安全扫描图标变绿**（🟢/🔵）再 **Publish**。若被 quarantine（🔴/🟡）：**不要删文件**，
      发邮件到 `support@nexusmods.com`（主题 `Quarantined File`）+ 附模组页链接。
- [ ] **C6. 发布后用 Vortex 实测装一次**（Vortex ≥1.9.10 + 官方 Palworld 扩展），确认它落到
      `ue4ss\Mods\PWProjection` 且写进 `mods.txt`。
- [ ] **C7. 以后更新**：在 **Manage Files** 给同一个文件追加新版本（勾 `archive existing file`），
      再 `POST changelog`/页面 changelog 追加一行。

## ④ 必测 / 待确认

### 🔴 2026-10-08 工坊首测暴露的两个问题（**先看这里**）

**问题 1（已定位并修，构建 `.113`）——「改键/保存设置后所有快捷键失效」**
- 现象（玩家原话）: 「进行几次改键+操作后，突然**什么按键都不管用了**，游戏里移动能正常进行」
- 根因（日志铁证）: 那一局点了 6 次保存 = 我们的 Mod 被 `restart_mod` **重载 6 次**；
  最后一次启动的日志写着 **`有 6 个键在绑定前已经是注册状态`** = 当时在用的**全部 6 个键**都拿不到注册
  ⇒ 按下去没有任何反应。**UE4SS 的按键 API 没有"注销"**（只有 `IsKeyBindRegistered` /
  `RegisterKeyBind`）⇒ 上一轮注册还占着键，**只有重启游戏能恢复**。
- **结论（产品行为）**: **改键 / 保存设置之后，必须重启一次游戏。** `.113` 会在重载后
  **弹屏幕提示"请重启游戏"**，文档也都改成了这句话。

**问题 2（2026-10-08 最终结论：**已知问题发布**）—— 崩溃 + 改键后的重载循环卡死**
- 现象: 重进游戏后**人物回到"最开始的位置"**（按键问题是上面那条）。
- 证据: `Mods\NativeMods\UE4SS\crash_2026_10_08_20_02_55.*.dmp`（43 MB）；
  `UE4SS.log` 在 20:02:52.958 **直接中断、没有任何 Lua 报错**（= 原生崩溃）；
  崩的时间点 = 第 7 次重载后 12 秒（投影刚重灌完 1430 实例）。
- 我写的 minidump 解析器读出: 两次崩溃（10-07、10-08）**都是 `0xC0000005`、异常地址都在
  `UE4SS.dll` 里**，故障线程栈上是"引擎 + AMD 显卡驱动 + UE4SS"混合 ⇒ 从游戏侧调进 UE4SS
  （大概率是它的 `ProcessEvent` 钩子）时解引用坏指针。**还没证明是我们的 mod。**
- **请按这个矩阵复现/排除**（每项跑 10~15 分钟，把当时的 `pwpr.log` 给我）:

  | # | 怎么测 | 想排除什么 |
  |---|---|---|
  | 1 | **完全不进设置页**、正常玩一局（放投影 + 建几件） | 会不会是"重载"这条路引入的 |
  | 2 | 连点 **6~7 次保存**（改键再改回来），然后放投影 + 建几件 | 复现 10-08 那次 |
  | 3 | 在设置页里把 `hud_enabled` **关掉**（屏幕提示关）再重复 #2 | 会不会是"提示控件清理"那条路 |
  | 4 | 把 `ghost_hide_place_batch`/投影都关掉，只跑采集与加载 | 会不会是投影重灌（1430 实例）那条路 |
  | 5 | 同样的操作，但**先重启游戏**再操作（不要靠重载） | 复现是否必须"重载"这个前提 |
  | 6 | 关掉我们的 mod（`mods.txt` 里 `PWProjection : 0`）玩一局 | 归因（项目的三步归因法第一步） |

  ⚠️ 在拿到 #1/#2/#5 的结果之前，**先不要把它改成 Public**（Hidden 状态下已经能订阅测试）。


1. **框架没有 button 类型**（已核实：`PalModOptionsClient.lua` 只支持
   `boolean / integer / number / text / enum / keybind / section`）⇒ 你想要的"单击触发探测的按钮"
   **做不了**，已按你的备选方案实施：**「渲染能力探测」= 「常用」第一条 + 默认 `N` + 开箱可用**。
   另外加了一个小机制 `bound_default = true`（值等于默认值也照常绑定），只给这一行用。
   ⚠️ **你自己机器上要看到新默认值**：你的 `PalModOptions\Scripts\config\PWProjection.ini` 里
   已经存着 `k_probe="F24"` ⇒ 框架会沿用旧值（`N` 还是按不了）。**两个办法**：
   ① 在设置页点一次 **「恢复默认值」**（这一行回到 `N`）；② 直接删掉那个 `.ini`（框架会用新默认值重建）。
   **全新用户没有这个问题**（默认就是 `N`）✓
2. **`H`（重新定位到脚下）默认不绑** —— 2026-10-09 玩家定稿: **不用改**，
   理由「并不会阻塞正常使用流程，大不了方向键移动就是了」。（`H` 想用就在设置页自己设一个键。）
3. **工坊更新会不会清掉用户数据（必测）**：我们的 `pwpr_config.json` / `pwpr_keys.json` /
   `pwpr_placements.json` / `pwpr.log` 就写在 `Scripts\` 里，而工坊 loader 在 `Version` 变化时
   会重装这个包。**间接证据是"不会清"**：你机器上 `PalModOptions` 的 `InstallManifest.json`
   只登记了它自己的文件（`Files`/`Dirs`），而我们的 `PWProjection.ini` 是运行时生成的、
   不在登记表里，却**一直在**（框架的用户设置也没丢）⇒ 推断 loader 只替换它登记的文件。
   **但必须实测**：先把 1.0.0 传成 Hidden → 订阅 → 进游戏改个键/放个投影 → 把 `Version` 改成
   `1.0.1` 再上传 → 看用户的 `pwpr_keys.json` / `pwpr_placements.json` 还在不在。
   如果**会清**，我再改成"把用户数据写到包目录之外"（代码改动 + 重新部署，半小时内能做完）。
4. **`MinRevision` 我填了 `100619`**（照你机器上最新更新过的工坊 mod `PalModOptions` 抄的；
   UE4SS 与 FirstPerson 用的是 `82182`）。发布前请对着游戏标题/版本号确认一次"当前版本后 5 位"，
   填高了可能拦住旧版本用户。
5. **Pocketpair《MOD 利用ガイドライン》正文抓不到**（站点是 JS 单页应用）⇒ 请用浏览器打开
   <https://guideline.palworldgame.com/palworld-mod-guideline> 扫一眼，确认没有"禁止注入类/改内存类 mod"
   之类的额外条款（官方上传工具的校验逻辑里没有这类限制，UE4SS 系模组也是官方支持类型）。
6. **工坊缩略图的像素尺寸官方没有规定**（只限 <1MB）。工坊列表页是方形展示 ⇒ 建议直接给方形图。
7. **N 网单文件大小上限的确切数字没查到**（技术上是单段 100 MiB、超过走 multipart）；
   我们的包只有几百 KB，**不构成问题**。
8. **描述里我不放"AI 参与"标签**（N 网规则是"如实标"）—— 这条你自己定：本项目的代码与文档是
   人机协作产物，要不要打 `AI-Generated Content` 之类的标签由你决定（打了不会被罚，漏打被举报才会）。
9. **中英双语**：N 网描述已按"英文为主 + 中文附后"写好（纯中文有被判"不可读"的风险）。
