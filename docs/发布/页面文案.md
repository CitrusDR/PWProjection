```
[h1]PWProjection — Blueprint Projection for Palworld[/h1]

[b]Capture your base into a blueprint, project it as a translucent blue hologram in any save, and rebuild it piece by piece — every piece automatically snaps to its hologram position the moment you place it.[/b]

[h2]What it does[/h2]
[list]
[*][b]Capture[/b] — stand inside a base, press [b]Y[/b]; buildings are saved to a plain-JSON blueprint (easy to back up / share)
[*][b]Load / cycle blueprints[/b] — press [b]J[/b]
[*][b]Project[/b] — press [b]K[/b] to place/hide the blue hologram (material can be switched)
[*][b]Build snap (the core feature)[/b] — no extra key: place a building normally and it lands on the matching hologram position; the placed piece disappears from the hologram immediately (no more flickering overlap)
[*][b]Height auto-fit / learning[/b] — on water or uneven terrain where the game refuses the blueprint's height, the whole projection is moved to the height the game allows (and calibrated to the real built height, once per site)
[*][b]Position + progress memory[/b] — remembers where the projection was and what you already built; multiple placement sites per blueprint, cycle with [b]U[/b]
[*][b]Layer view[/b] ( [b]L[/b] ), [b]nudge/rotate/material[/b] with the arrow keys ( [b]F9[/b] switches mode), [b]H[/b] re-centers the projection to your feet
[*][b]In-game settings page[/b] (needs Mod Options Framework) — rebind keys and edit numbers inside the game
[/list]

[h2]Required / Install[/h2]
[list]
[*][b]Requires UE4SS[/b] — subscribe to [b]UE4SS Experimental (Palworld)[/b] (declared dependency; it should be installed together)
[*]In game: [b]Options → Mod Management → Enable Mod = ON[/b], tick [b]PWProjection[/b], [b]Save[/b] (the game restarts)
[*]In-world, press [b]N[/b] once — the capability probe (required the first time; it unlocks projection automatically)
[*]Recommended: [b]Mod Options Framework[/b] by Elvlin — gives you the in-game settings page (Esc → Mod Options → PWProjection)
[/list]

[h2]Keys[/h2]
[list]
[*][b]Always available[/b]: [b]N[/b] probe · [b]Y[/b] capture · [b]J[/b] load blueprint · [b]K[/b] projection on/off · [b]L[/b] layer
[*][b]Unbound by default[/b] (bind them in Esc → Mod Options → PWProjection): [b]H[/b] re-center, [b]U[/b] cycle sites, [b]F9[/b] arrow-key mode, [b]F7[/b] help/status, [b]F8[/b] reload config
[*]Key/config changes need a game restart ([b]F8[/b] reloads only the config file)
[/list]

[h2]Known limitations (by design)[/h2]
[list]
[*]The game's own ghost preview does not snap — only the actually placed piece does
[*]Removing a building does not restore its hologram (that auto-scan crashed the game in testing) — press [b]K[/b] twice to refresh
[*]Multi-part assemblies render as their main part only
[*]Multiplayer is untested
[/list]

[h2]Troubleshooting[/h2]
[list]
[*]Projection locked when pressing [b]K[/b] → press [b]N[/b] once
[*]A key does nothing → it may be unbound; bind it in the settings page
[*]No snapping → check [b]Scripts\pwpr.log[/b] for [b][bsnap][/b] lines; most often the projection itself is mis-placed → press [b]H[/b]
[*]Reporting a problem? Please attach [b]pwpr.log[/b] (first line tells the exact build)
[/list]

[h2]Credits[/h2]
[list]
[*][b]UE4SS[/b] — Lua runtime (not bundled)
[*][b]Mod Options Framework[/b] by [b]Elvlin[/b] (MIT) — in-game settings page
[*]Architecture informed by [b]Simple Building Blueprints (SBB)[/b] — read-only reference, no code reused
[/list]

[h2]Known issue / 已知问题[/h2]
[list]
[*][b]改键之后不要快速连点保存[/b]：在设置页改一个键会让保存触发"重载本模组"，连着点会进入重载循环（约 0.44 秒一轮），几十轮后[b]游戏可能卡死[/b]。改完[b]点一次[/b]保存、等它生效再改下一项就好；[b]不改内容[/b]时随便点（不会重载）。万一卡住：结束进程重开即可，[b]配置/键位/建造进度都不会丢[/b]。
[*]想彻底避开：在 [code]Scripts\pwpr_config.json[/code] 里加 [code]"options_apply_mode": "game_restart"[/code] ⇒ 保存后不再重载、只提示重启游戏（功能全在，改完重启一次生效）。
[*]已知的偶发崩溃：极少数情况下游戏会崩（日志里会写 [code]pwpr.log[/code]）。遇到请把 [code]Mods\NativeMods\UE4SS\crash_*.dmp[/code] 和 [code]pwpr.log[/code] 发到评论区/issue，会继续修。
[/list]

[h2]Video / 视频演示[/h2]

[h2]怎么用[/h2]
[list]
[*][b]前置[/b]: 订阅 [b]UE4SS Experimental (Palworld)[/b]（本模组依赖它）；进游戏 [b]Options → Mod Management[/b] 打开 [b]Enable Mod[/b]、勾上本模组、[b]Save[/b]（游戏会重启）
```
