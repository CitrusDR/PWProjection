## 一、Nexus Mods（需要替换 ✓）

**用这个文件**：`docs\发布\N网描述_最终版.md`（148 行，**反引号 0 个**）

结构（英文在前、中文在后，两边章节一一对应）：
```
## PWProjection — Blueprint Projection for Palworld      ← 英文段
   Features / Requirements / Installation (manual) / Keys
   Known limitations (by design)   ← 2026-10-08 补
   Troubleshooting                 ← 2026-10-08 补
   Known issues / Credits / Video / Source and license
## PWProjection —— 建筑投影（Litematica 风格）中文说明      ← 中文段
   功能 / 前置要求 / 安装（手动）/ 按键
   已知限制（设计如此）             ← 2026-10-08 补
   排错                            ← 2026-10-08 补
   已知问题 / 致谢 / 视频演示 / 源码与许可
```

**替换操作**
1. 打开 mod 页面 → `Edit mod`（或上传向导里那一步）→ **Full description**
2. **Ctrl+A 全选删掉** → 粘贴 `N网描述_最终版.md` 的**全部内容**
3. 若标题/列表没渲染成样式：用编辑器右上 **`Import description`** 重新粘一次
   （N 网是 Markdown/WYSIWYG，**不要**用 BBCode，**不要**用行内反引号 —— 会变成灰框把句子切碎）
4. 底部 **`Save`**（页面已 Published，Save 立即生效）

## 二、Steam 创意工坊（**不需要改动** ✓）

核对结果：`页面文案.md:99` 的 `[h2]Known issue / 已知问题[/h2]` 里**已经有**「已知的偶发崩溃 ⇒ 请发 `crash_*.dmp` + `pwpr.log`」那句 ✓
工坊页面内容与 N 网版**已对齐**（含设计上的已知限制、Troubleshooting、按键、致谢、视频）。

> 工坊格式提醒：那个平台是 **BBCode**（`[b]` `[list]` `[h2]` `[code]` `[url=]`），
> 文案在 `页面文案.md` 的工坊段；**Markdown 语法在工坊里不生效**（`**粗体**` 就是两个星号）。
> 改工坊页面时**只改 Change Notes**（版本更新），正文一般不用动。

## 三、两边语法差异速查（完整版见 `更新发布流程.md` 第 1 节）

| 用途 | 创意工坊（BBCode）| Nexus（Markdown）|
|---|---|---|
| 粗体 | `[b]字[/b]` | `**字**` |
| 标题 | `[h2]标题[/h2]` | `## 标题` |
| 列表 | `[list][*]项[/list]` | `- 项` |
| 路径/代码 | `[code]路径[/code]` | 直接写纯文本（**别用反引号**）|
| 链接 | `[url=网址]文字[/url]` | `[文字](网址)` |
| 分隔线 | `[line]` | `---` |
