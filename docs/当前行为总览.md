## 1. 它是什么 / 做到哪了

把基地**采集**成蓝图（`*.blueprint.json`），然后在任意位置以**半透明幽灵**投影出来，
一层一层看、随手挪、**放下的建筑自动从投影里消失**（避免"蓝色投影 + 彩色实物"重叠闪烁）。

**已完成并实机验证**:

| 功能 | 状态 |
|---|---|
| 采集（范围 / 全部）→ 蓝图文件 | ✓ 可用 |
| 投影（幽灵、材质、分层、骨骼网格、微调、旋转） | ✓ 可用 |
| **建造吸附**（放下建筑时自动吸到投影对应位置） | ✓ 可用（`buildsnap_*` 参数可调） |
| **已放上的不再投影**（3 秒批量结算） | ✓ 可用 |
| **位置 / 进度记忆**（多处记录、`U` 切换、跨存档沿用） | ✓ 可用 |
| **拆掉自动恢复**（扫描只减不增） | ✓ 可用（按 `K` 时核对） |
| 屏幕提示 | ✓ 可用（按 `O` 探测通道） |

## 3. 「已放上」名单（哪些件不再画）—— 只有两个来源

1. **精确通道**：建造吸附在改写放置请求时**明确知道**"我正要往第几条记录放"
   ⇒ 直接登记（不需要猜）✓
2. **记录里存的进度**：`pwpr_placements.json` 里每一处的 `placed` 列表 ✓

**扫描（枚举关卡建筑）只做一件事：只减不增** ——
名单里的每一条，用它在该锚点下的**世界坐标**去找附近（默认 40 厘米，`ghost_hide_placed_cm`）
有没有真实建筑：**在 ⇒ 继续不画；不在 ⇒ 恢复渲染**（拆掉自动恢复）。
**扫描绝不往名单里加**（原因见 `踩坑记录.md` 的"扫描认领是歧义的"一条）。

**3 秒批量窗口**：连放时先入队，安静 3 秒（`ghost_hide_placed_batch_s`）后一起结算，
只重灌受影响的组件（不重灌整个投影）。

## 4. 位置 / 进度记忆 —— 两个半径，各管各的

（详细表格见 `docs\配置说明.md` 第 0.4b 节）

| 用途 | 半径 | 为什么 |
|---|---|---|
| **`K` 沿用** | **蓝图包围盒一半 + `ghost_resume_margin_m`**（这张蓝图 ≈ 53 米，宽）| `K` = "对齐到这个世界"：站在基地任何角落按 `K` 都该认出"我在哪一处"，沿用它的位置 + 朝向 + 偏移 + 进度 |
| **登记 / 写回进度** | **`ghost_site_merge_m`**（默认 **10 米**，紧）| 只有"就在这一处旁边"才算同一处 ⇒ 换个地方建 = **新的一处** ✓ |
| **`H`** | **完全不查** | 放脚下 + 名单清空 + 完整重灌 ⇒ 一份完整的新投影 ✓ |
| **`U`** | 不看距离 | 按创建顺序切记录 ✓ |

* 判定比的是**水平距离**（**忽略高度 z**）—— 同 x/y 不同高度算同一处（取舍见 §6）
* **记录只由"真放过建筑"产生**（`bind_progress`）；只挪投影不会新增记录 ✓
* `K` / `H` / `U` 都会**完整重灌**（`refresh_projection(..., rebuild = true)`）——
  只搬变换的"省事路径"会让上一处的隐藏状态残留 ✗（踩过，见 `踩坑记录.md`）

## 5b. ★ 自动机制一览（"它自己会做什么"）

> 想知道**实现方式**（用哪些引擎接口 / 什么数据结构 / 什么时候碰引擎）⇒ 看
> **[`docs\实现方式.md`](实现方式.md)**（我们自己的做法，19 个模块的职责表也在那里）。
> 这一节只讲**玩家视角**: 什么条件触发、它会做什么。

> 这一节回答"我什么都没按，它为什么动了/没动"。每条都写清**触发条件**与**后果**。

| 机制 | 触发条件 | 它会做什么 |
|---|---|---|
| **建造吸附（拦 + 重发）** | 手拿建筑按"放置"，且**投影正显示着**、类型/距离对得上 | 拦下游戏的原请求（把 id 改成 `None`），然后**排到下一帧**按投影坐标**重发一次**（`buildsnap_defer`，2026-09-29 的机制修复）。位置/朝向/高度按配置（默认三者都吸）|
| **★ 高度自适应**（"吸附后的高度游戏不认 ⇒ 自动挪投影高度"）| 重发之后 1.2 秒内**没有新建筑出现**（= 游戏拒了这次放置）**且这次改过高度**，并且能算出 `dz = 游戏允许的高度 − 我们发的高度`（要求 5 厘米 ≤ \|dz\| ≤ 500 厘米）| **自动把整份投影的高度挪 `dz`**（`Session.offset.z += dz`）。它走的就是"微调"那条路 ⇒ 顺带**记进位置记忆**（下次还生效）、**重画投影**、并**弹提示**告诉你是"高度不被允许"才自动调的；`F7` 状态里也能看到当前偏移。<br>⇒ **再放一次就用修正后的高度**，而且**高度继续跟投影**（不是"以后不吸高度"）。<br>日志: `[bsnap] ★ 高度自适应: … 吸附的高度被游戏拒绝 ⇒ **投影 Z 偏移 +23 厘米** ⇒ 现在 偏移(…)`<br>不满意就用方向键 / 小键盘 `9`、`3` 手动微调（和普通微调一样）|
| **高度差不判** | 匹配到的那一件与你的放置点**高度差 ≤ 人物半高**（实测 **88 厘米**；这个值就是 `K` 放投影时读的**胶囊体半高**）| 半径闸 / 修正量上限 / "已经够准"这三处**都按平面距离判**（高度差**不**参与）⇒ 避免"明明站得很准却吸不上"（水面/地形/楼上楼下时高度差几十厘米是常态）|
| **被拒 ⇒ 只吸平面**（本次会话内）| 前面那次"改了高度"的重发**被拒**、而且投影高度**挪不了**（没投影 / 差值不合理）| 同一类建筑**之后只吸 x/y**（不动高度）；**马上再放一次**就是降级后的策略（故意不设"这条记录刚被拒"的闸，就是为了让这次重试能落地）|
| **崩溃 / 卡死记忆** | 上一次会话在**重发**那一步卡死/崩溃（判据: 黑匣子 `● 重发前 …` 有登记，但**没有** `● 重发返回`）| **只记录**（启动时写日志 + `F7` 一行），**不再改变任何行为** —— 曾经的"整类拉黑 / 整片拉黑 / 限制修正量"三种做法都被玩家否掉（见 `踩坑记录.md` §68-12/§68-14）。记忆跨会话保存在日志里（`● 记忆 frozen …`）；**重置 = 删掉/移走 `pwpr.log`** |
| **黑匣子（同步落盘）** | 放置路径的每个关键步骤（`● 钩子被调用` / `● 请求` / `● 即将拦原请求` / `● 拦截结果` / `● 重发前` / `● 重发返回`）| 每步**立刻写盘一行**（`Log.solid`，**不走**攒批缓冲）⇒ 游戏卡死/崩溃时也留得下证据（普通日志在那种时刻会把最后一段丢掉）|
| **「已放上」就不画**（两个来源）| ① 吸附时"就知道往哪一条记录放"（精确通道）；② 记录进度里已经有它 | 只靠这两个来源；**扫描只减不增**（不会凭空认领别处的建筑）—— 详见 §3 |
| **放置批量清算** | 连续放置时（默认窗口 3 秒）| 窗口内只记账，**停下来**之后一次性把这段时间放上的件从投影里去掉（省重灌）—— 详见 `ghost_hide_placed_batch_s` |

## 6. 已知取舍 / 限制（重要）

| 取舍 | 说明 |
|---|---|
| **`H` 那一份不跑扫描** | 所以 `H` 之后**拆掉**某件，投影不会自动恢复 ⇒ 按一次 `K` 让它重新核对世界 |
| **非本模组放的老建筑不会自动识别** | 扫描只减不增 ⇒ "旧基地继续建"要按 `K`，用吸附逐件放（精确通道会登记）|
| **判定忽略高度** | 同 x/y 不同高度（楼上 / 地道）算同一处；想区分就把两个半径都调小 |
| **`level.Actors` 会保留已摧毁的 actor** | 所以"查引用还在不在"的快路径默认关闭（`ghost_hide_alive_check`），拆掉恢复靠全扫 |
| **少部分建筑画不出来** | 见 `mod\PWProjection\已知限制.md`（缺网格 / 骨骼映射）|
| **原生崩溃不可归因到单次 Lua 调用** | 所以关键路径都有日志点与开关 ✓ |

### 7b. 「放置时卡住 / 游戏无响应」怎么查（2026-09-29 新增，**已用它抓到一次真凶**）

> **实测案例**（水面玻璃地基，整局冻死只能强杀）: 黑匣子最后一行是
> `● 重发前: 即将调用 RequestBuild_ToServer → …`，**没有** `● 重发返回`
> ⇒ 卡死点 = **我们拦下原请求、按吸附坐标重发的那一次调用里**（引擎没返回）。
> 完整取证与修法见 `docs\踩坑记录.md` §68。

> ⚠️ **先知道一件事**: `pwpr.log` 是**攒批落盘**的（攒够 200 行或隔 5 秒才写一次盘）。
> 所以**游戏线程一旦卡死，最后一次落盘之后的行全丢** —— 卡死现场光看普通日志可能什么都看不到。

为此放置路径上有一组**同步落盘**的"黑匣子"行（`Log.solid`，每次请求都写、立刻进磁盘）:

```
[bsnap] ● 钩子被调用（第 N 次请求）
[bsnap] ● 请求 #N id=… 位置=… 朝向=… 附加参数=true/false（…）
[bsnap] ● 已经够准（差 x 厘米）⇒ **不动这次请求**（原样放行）
[bsnap] ● 干跑（不改游戏）: 本来要改发到 (x,y,z) 朝向 …；游戏原位置=… 差 … 厘米；附加参数=…
[bsnap] ● 原样放行（没插手）: 这次请求带了附加参数（…）⇒ 不动它（怕像水面地基那样把游戏卡死）
[bsnap] ● 即将拦原请求: 目标记录 #N 差 x 厘米 → 把请求里的 id 改成 None
[bsnap] ● 拦截结果: 拦住了/没拦住（…）
[bsnap] ● 重发前: 即将调用 RequestBuild_ToServer → (x,y,z) 朝向 …（若后面没有「● 重发返回」⇒ 就卡在这一次重发里）
[bsnap] ● 重发返回: OK / 失败 …
```

判读（**最后一行 `●` 就是卡住的位置**）:

| 看到 | 结论 |
|---|---|
| 连 `● 钩子被调用` 都没有 | **我们的钩子没被调用** ⇒ 卡死与吸附无关（查游戏/存档本身，或这种建筑走的不是这个请求）|
| 有 `● 钩子被调用` 但没有 `● 请求 #` | 钩子进来了，但**前置条件不满足**（没开 `buildsnap_enabled` / 没投影 / 没蓝图 / 模式不对）⇒ 我们没动游戏 |
| 有 `● 请求`，没有 `● 即将拦原请求` | 我们**没动游戏**（原样放行，原因看缓冲里的普通日志）⇒ 卡在游戏自己那边 |
| 有 `● 即将拦原请求`，没有 `● 重发返回` | **卡在我们的"拦 + 重发"里**（**已实测遇到过一次**）|
| 全部行都齐 | 这条链走完了 ⇒ 卡在之后的游戏逻辑 |

**零风险的取证手段**: 把 `buildsnap_dry_run` 设成 `true`（`F8` 即时生效）—— 它
**只匹配、只记账、什么都不改**（不拦、不重发）⇒ **不可能卡死**，但会写下
`● 干跑（不改游戏）` 那一行（含 id / 目标坐标 / 差多少 / 附加参数）。
排查"某种建筑一放就卡"时**先跑它**。

**高度自适应 + 危险类型拉黑**（`.56` 起，玩家 2026-09-29 提的方案）:

* 默认**仍吸高度**（`buildsnap_snap_z = true`）；
* ★★ **高度差 ≤ 人物半高（实测 88 厘米）时不判高度**，半径闸/修正量上限都按**平面距离**判
  （否则几十厘米的高度差会被算进距离 ⇒ 明明站得准却"吸不上"）；超过半高才用三维距离；
* **改了高度被游戏拒了** ⇒ **自动把整份投影的高度挪到游戏允许的位置**
  （`Session.offset.z += dz`，`dz = 游戏允许高度 − 我们发的高度`；弹提示 + 记进位置记忆）
  ⇒ **再放一次继续吸高度**；
* ⚠️ **记住的原则（2026-09-29 玩家纠正）**: **不能"为了不崩就关掉吸附"**
  （上一版整类/整片拉黑被否掉：「跟没有这个 mod 有啥区别」「几乎贴上去的都不吸附了」）。
  现在: 出事过的类型**只是不动高度**（x/y 照吸）；危险区域**默认不启用**；
  防崩改用 ★★ **精细吸附窗口** `buildsnap_safe_cm`（**默认 80 厘米**）——
  只吸窗口内的小修正，超出就原样放行并**明说是哪条限制、怎么放宽**。
  （依据: 三次事故的修正量是 93/110/143 厘米；"贴上去"从来没出过事。）
* 记忆写在日志里（`● 记忆 frozen id=… stage=…` / `● 记忆 zone x=… r=…`，每次启动重新登记）；
  **重置 = 删掉/移走 `pwpr.log`**；
* **吸附不上怎么自查**: 看 `匹配:` 那一行（现在带**目标坐标 / 请求坐标 / 分轴差**）——
  上面那句 `要挪 X 米（超过上限 2.0 米）⇒ 原样放行` 的意思是"**你放的位置附近确实没有投影件**"
  （不是吸附坏了）。要么摆准一点，要么把 `buildsnap_max_jump_cm` 调大（默认 200 厘米）。

`F7` 里会显示 `建造吸附降级: 卡死记忆[…] 本次被拒后降级[…]`。

对照实验（成本很低，能一刀切开责任面）:
① 按 `K` 收起投影 **且** 把 `buildsnap_enabled` 改成 `false`（`F8`）⇒ 还卡 = 游戏/存档自己的问题；
② 只关 `buildsnap_enabled`（投影留着）⇒ 卡 = 是**投影**影响游戏的放置；
③ 都开着 ⇒ 卡 = 那条"拦 + 重发"的路（**水面地基那次就是这一条**）。
