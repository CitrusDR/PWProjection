# PWProjection —— 支持的按键名（完整清单）

> **这份文档回答**: `pwpr_keys.json` 里的值**能写什么**。
> 按键绑定的**唯一文件**是 `…\Mods\PWProjection\Scripts\pwpr_keys.json`
> （**不存在会自动生成一份**，里面 11 个键都写着默认值，直接改即可）；
> 改完**必须重启游戏** —— 按 `F8` 只重载 `pwpr_config.json`，**不会**重绑按键。
> 相关: `docs\配置说明.md` 的「按键绑定」一节、`docs\当前行为总览.md` §2、
> 工作区 `AGENTS.md` 规矩 3d（改按键的规矩）。

> ★ **清单来源**: UE4SS 自带的官方 `Mods\Keybinds\Scripts\main.lua` 里那张
> 「Valid keys」表 —— 也就是**本机 UE4SS 版本实际认的全集，共 165 个**。
> 抓取日期: 2026-10-06。

---

## 一、怎么写

```json
{
  "key_resnap": "G",
  "key_capture": "NUM_EIGHT"
}
```

* 值必须**原样大写**：`"Y"` ✅、`"y"` / `"Key.Y"` ❌；
* **只写你要改的**（删掉某一行 = 用内置默认值）；
* 不合法 / 游戏自己占用 / 和别的动作撞键 ⇒ **自动回退内置默认值**，
  并在启动日志与 `F7` 里写清原因；
* 每次启动都会读一次；**改键必须重启游戏**。

## 三、本项目当前的按键（默认值）

| 动作 | `pwpr_keys.json` 里的键 | 默认值 |
|---|---|---|
| `capture` | `key_capture` | `Y` | 采集（半径见 `capture_radius_m`） |
| `library` | `key_library` | `J` | 蓝图库: 下一张并加载 |
| `ghost` | `key_ghost` | `K` | 投影: 放 / 收 |
| `layer` | `key_layer` | `L` | 投影: 切分层 |
| `site_cycle` | `key_site_cycle` | `U` | 投影: 换一处记录 |
| `resnap` | `key_resnap` | `H` | 投影: 重新定位到你脚下 |
| `mode` | `key_mode` | `F9` | 切换方向键模式（★ 2026-10-06 已**合并成一个键** —— 以前 `F9`/`F10` 都能切的别名删掉了） |
| `probe` | `key_probe` | `N` | 渲染能力探测（S3） |
| `notify_probe` | `key_notify_probe` | `O` | 屏幕提示通道探测（S9） |
| `help` | `key_help` | `F7` | 帮助 / 当前状态 |
| `reload` | `key_reload` | `F8` | 重载 `pwpr_config.json`（★ 不会重绑按键） |

**不进配置的"别名"**（按 规矩 4c 只当"有的话顺便能用"）:

* 小键盘: `NUM_EIGHT`/`NUM_TWO`（前/后）· `NUM_FOUR`/`NUM_SIX`（左/右）· `NUM_NINE`/`NUM_THREE`（上/下）
  · `ADD`/`SUBTRACT`（旋转）· `NUM_FIVE`（清偏移）· `NUM_ZERO`（步长）· `MULTIPLY`（换材质）
  · `NUM_ONE`（紧急收回提示控件）
* 方向键: 移动 / 旋转 / 材质（由 `key_mode` 切换模式）；
* 投影对齐（`snap_key`）: **默认不绑**，想用就在 `pwpr_config.json` 里设一个空闲字母。

## 四、**已知被占用**的键（别选）

| 键 | 谁占的 |
|---|---|
| `B` | **游戏自己** —— 建造模式入口（写进 `pwpr_keys.lua` 的 `Keys.RESERVED`，填了会被拒绝）|
| `F1`–`F4` | UE4SS |
| `F5` / `F6` | FirstPerson mod |
| `F11` / `F12` | 全屏 / 截图（游戏）|
| `Ctrl`+`O` | UE4SS GUI 控制台开关（`ToggleGuiKey = O`）|
| `Ctrl`+`H` / `Ctrl`+`J` / `Ctrl`+`6`~`9` | UE4SS 官方 dump 快捷键（`Mods\Keybinds`）|

> ⚠️ 因为 UE4SS **按住修饰键也会触发裸键**，用上面的 `Ctrl+X` 时**会顺带触发我们的同名键**
> （例如 `Ctrl+H` 会把投影拉到你脚下）—— 见 `docs\项目状态与路线图.md` §5.3b/7.3。

## 五、改完怎么验证

1. 启动后看日志（`Scripts\pwpr.log`）里的几行:
   `按键文件: pwpr_keys.json …` / `按键绑定: 11 个动作 …` / 每个动作一行 `动作 键 来源`；
2. 游戏里按 `key_help`（默认 `F7`）：**整张表会写进 `Scripts\pwpr.log`**（还有 UE4SS 控制台窗口），
   写的是**你实际生效的键**。⚠️ **屏幕上只会闪一行摘要**（不是完整表格）——
   想看表就去日志里搜 `PWProjection 帮助`；
3. 故意写错一个（例 `"ZZ"`）⇒ 那一行会被回退成默认值，并写明原因 —— 说明校验在工作；
4. 如果日志里出现 `按键文件: … 格式不对 …`：说明你手改的 JSON 有语法错
   （漏逗号 / 多逗号最常见）—— 原文件会自动备份成 `pwpr_keys.bad.json`，
   同时重新生成一份默认的；照着备份重做一次改动即可。
