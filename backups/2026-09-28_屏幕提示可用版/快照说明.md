### ⚠️ 已知未修（**故意留着的**，不要当成回归）

| 问题 | 现状 |
|---|---|
| **"回标题 → 重进世界"后第一次操作可能闪退** | 根因：上个世界的对象已销毁，而 `Util.usable()` / `IsValid()` 会**撒谎**（返回 true）⇒ 拿废控件 `SetText` → 访问违例。为修它加的"世代守卫"因**标记不稳定**曾把正常放置搞坏（每次 `0 件`、提示堆屏），所以**做成开关 `world_guard_enabled` 并默认关闭**。<br>**绕法**：回标题后重启游戏；或 `notify_own_widget = false`（提示只走控制台，完全不碰 UI） |
| 提示颜色不可自定义 | `_G.FLinearColor` / `_G.FSlateColor` 未暴露，构造不出 `SetColorAndOpacity` 的结构体。换控件类 = 改配置 |

## 恢复方法（把快照装回去）

```powershell
# 1) 覆盖工作区（先备份你现在的改动！）
Copy-Item -Recurse -Force "mod","docs" "D:\dsh-workspace\palworld-litematica\"

# 2) 部署到游戏（脚本会把 15 个 Lua 复制到 UE4SS 的 Mods 目录）
powershell -NoProfile -ExecutionPolicy Bypass -File ".\mod\PWBlueprint\deploy.ps1"

# 3) 核对没被动过（逐行对比 SHA256）
#    见 校验清单.txt
```

> 部署脚本只往 `Mods\NativeMods\UE4SS\Mods\PWBlueprint\` 写 Lua 文件，
> **不碰存档、不碰游戏本体**。

```
hud_enabled              = true      # 屏幕提示总开关
notify_own_widget        = true      # 用自建控件（false = 只走控制台，零 UI 风险）

notify_widget_text_child = "Text_Warning"

hook_load_map_pre        = false     # LoadMapPre 钩子：默认关
ghost_enabled            = true      # 投影已解锁（N 探测通过后设的）
```
