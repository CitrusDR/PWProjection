## 明确**关掉**的（有原因，别贸然打开）

| 键 | 默认 | 为什么关 |
|---|---|---|
| `ghost_hide_scan` | `false` | 周期性扫描"被拆掉了" —— `level.Actors` **保留 pending-kill 对象**，拆完建筑后读它就是**原生访问违例**（`pcall` 抓不住；本机崩过两次）。拆掉后按 `K` 收起再放一次即可 |
| `ghost_hide_alive_check` | `false` | 对可能已销毁的 actor 调 `Util.valid()` —— 同类原生崩溃风险，且它本来就报"全部存活"、不灵 |
| `buildsnap_notify` / `buildsnap_notify_confirm` | `false` | 放置时弹提示 = **体感卡顿主因**（引擎控件调用 + 原来每步写盘）；想要每件反馈再开 |
| `notify_trace` | `false` | 发提示的分步诊断日志（明显变慢），只在排查"发提示崩了"时开 |
| `snap_on_place` | `false` | 放投影时自动对齐到已有建筑（会和手动微调打架） |

## 未完成 / 暂不可用

* **`buildsnap_mode = "blueprint"`**（准星指着投影哪件就建哪件）——
  蓝图类型是**类名**、游戏认的是另一套 id（`Wood_Foundation` ≠ `Wooden_foundation`），
  必须先"学到"才发得出去；材料还按**投影那件**算。设了会告警，**请用 `align`**。
  只服务它的两个键已归到配置第 3 组。
* **"半透明预览也跟着吸"** —— 需要找到游戏 Ctrl 对齐的"选目标"函数（路线图 待办 2b 的 ③）。
* **纯格点吸附**（对齐到游戏建造网格）—— 路线图待办，未开始。

## 这一版修掉的关键问题（本轮 §43–§62，详见 `docs\踩坑记录.md`）

| 现象 | 根因 / 修法 |
|---|---|
| `align` 模式"按下去没反应" | 内层 `local res` **遮蔽**外层变量 ⇒ 算完就丢（合法 Lua、检查器也拦不住）⇒ 已修，并给静态检查器加了**第 12 项**硬拦 |
| "提示已放到投影位置，但什么都没建出来" | ① 目标在 11~25 米外（游戏不接受）＋ ② 高度被吸到投影的 z（陷地/悬空）⇒ 加分档选择 + 距离闸 + 默认吸高度可配 |
| 配置文件里另起一个 `{}` ⇒ **整份配置失效** | 改成"容忍 + 合并 + 大声告警"，并要求键写在同一个 `{}` 内 |
| `blueprint` 模式发出的是**类型名**而不是游戏 id | 类名 ≠ 游戏 id；改为"学到过才发，学不到就不发"，并标为**未完成** |
| "看不出来到底吸没吸上" | 新增**演示模式**（放宽参数肉眼可见）＋ 反馈带**具体数字**（修正多少厘米） |
| 连放时卡 / 偶尔漏一块 | 采纳玩家方案: **批量窗口**（连放只入队，停下 3 秒统一处理）＋ 确认改**先进先出队列** |
| 每次放置都卡一下 | 真凶: 发提示**每一步都同步写盘**（一条提示 7 次）＋ 每次都重灌整个投影 ⇒ 已修（缓冲 + 节流 + 增量重灌） |
| 放置瞬间仍有一点卡 | 引入 **`buildsnap_min_cm`**（差 ≤5 厘米**完全不插手**，省掉"游戏侧做两遍活"） |
| 拆掉后投影不恢复 / 不结算 | `Placed.deps` 漏注入（兜底扫描一次都没跑）+ 提前 return 漏记账 ⇒ 已修 |
| **崩了两次** | 对**已摧毁的 actor** 调 `Util.valid()` / 读 `level.Actors` 里的 pending-kill 对象 ⇒ 原生访问违例。**pcall 抓不住原生崩溃** ⇒ 把这两条路默认关掉（见上面"明确关掉的"） |
| 修好功能后"每次刷新都卡" | 那个全扫**以前没跑过**，功能一生效代价也生效 ⇒ 改为**只读关心的类型 + 分片扫描** |

## 怎么用这份快照 / 怎么恢复

```powershell
# 1) 解压到任意目录，然后部署进游戏（脚本会注册 mods.txt）
powershell -NoProfile -ExecutionPolicy Bypass -File .\mod\PWProjection\deploy.ps1

# 2) 进游戏: 按 N 做一次能力探测（通过后自动开启投影开关）→ 按 K 放投影 → 正常盖房子
#    （放下那一刻会自动落到投影上；放好的那一件会从投影里消失，不再和实物重合闪烁）

# 3) 想核对完整性: 用 校验清单.txt 里的 SHA256
```
