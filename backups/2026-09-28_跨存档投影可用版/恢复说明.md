# 恢复说明 —— 这份快照是怎么找回来的（2026-09-28）

## 发生了什么

打"改名后"的新快照时，我**误用了这个目录的旧标签**，`make_snapshot.ps1` 按设计会
"删掉同名目录再重建" ⇒ 这个目录被覆盖了。

* `快照说明.md` / `校验清单.txt` —— **曾经提交过**（提交 `d13a34b`）⇒ 已用
  `git show d13a34b:<路径>` **按字节原样取回**（字节数与原文件一致：3743 / 6957）；
* `PWBlueprint_…zip` —— **从未进过 git**（被 `.gitignore` 的 `backups/**/*.zip` 拦住）
  ⇒ 原始字节**找不回**，但它的内容就是" **改名前最后一版**的 mod + docs + tools"，
  这些**全都在 git 里** ⇒ 已用下面这条命令**重建**：

  ```powershell
  git archive --format=zip -o backups\2026-09-28_跨存档投影可用版\PWBlueprint_2026-09-28_跨存档投影可用版.zip 52fb288 mod/PWBlueprint docs tools
  ```

  （提交 `52fb288` = 改名前最后一次提交，含全部 20 个 `mod/PWBlueprint/*` 文件）

## 重要提醒：重建包的哈希与原包不同

`校验清单.txt` 最后一行记的是**原压缩包**的 SHA256 —— 重建包的字节**不会**等于它
（`git archive` 的压缩方式/时间戳与 `Compress-Archive` 不同，体积 403 KB vs 原来的 400 KB）。

⇒ 想核对**内容**，请看清单里**逐文件**的 SHA256（那些描述的是该快照时刻的文件内容，
对应 git 提交 `d13a34b` 的工作区状态）。
